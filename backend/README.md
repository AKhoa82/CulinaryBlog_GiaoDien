# Backend Service - Culinary Blog API (Khung Sơ Khởi)

Thư mục này được khởi tạo sẵn dành cho việc phát triển tầng Backend / API sau này của đồ án "Culinary Blog".

## Định hướng kiến trúc dự kiến:
- **Ngôn ngữ & Nền tảng**: Node.js (NestJS / Express) hoặc Go / Python FastAPI.
- **Cơ sở dữ liệu**: PostgreSQL / MySQL / MongoDB kết hợp Prisma ORM hoặc Drizzle ORM.
- **Xác thực**: JWT, Auth.js / NextAuth Session Adapter, OAuth2 (Google, Facebook).
- **Lưu trữ tệp đa phương tiện**: Cloudinary / AWS S3 / Firebase Storage cho hình ảnh công thức và ảnh đại diện người dùng.
- **Tài liệu API**: OpenAPI / Swagger UI.
